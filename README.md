# Kumari Palak – Portfolio

Plain HTML/CSS/JS. No build step.

## Files
index.html · styles.css · script.js · images/ · README.md

## Edit
Open script.js. Fill LINKS (LinkedIn, LeetCode, resume) and the PROJECTS list. Replace every [PLACEHOLDER] text.
Add screenshots to images/ and swap the `.shot` box in script.js for an <img> with alt text.

## Run locally
Open index.html in a browser, or run `python -m http.server 8000` and visit http://localhost:8000

## Publish free (GitHub Pages)
1. Create a public GitHub repo (e.g. `portfolio`) and upload these files.
2. Repo Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`, Save.
3. After ~1 minute your URL is https://Palak1016.github.io/portfolio/
